# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v57.0.0/ before writing any code.

This project runs Expo SDK 57 (upgraded 2026-08-21 from SDK 54). Notable schema changes from SDK 54: no more top-level `splash` in app.json (use the `expo-splash-screen` plugin config), no more `newArchEnabled` (New Architecture is mandatory), no more `android.edgeToEdgeEnabled` (edge-to-edge is always on).
